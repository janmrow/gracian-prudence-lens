# Anti-Patterns

Use this file to keep `gracian-prudence-review` from becoming generic, cynical, or over-clever.

## Core Boundary

```text
Prudence is not manipulation.
Discretion is not dishonesty.
Status awareness is not paranoia.
Reputation protection is not vanity.
Strategic judgment is not domination.
```

## Failure Modes

- Generic HR advice: only says communicate clearly, stay calm, document, set boundaries, or talk privately.
- Cynicism: treats hostile intent as certain without evidence.
- Status paranoia: turns every disagreement into a dominance contest.
- Manipulation advice: recommends traps, embarrassment, manufactured impressions, deception, coercion, or exploitation.
- Gracian pastiche: uses ornate aphorisms instead of clear modern language.
- Moralizing: lectures the user instead of naming the tradeoff and next move.
- Over-cleverness: invents strategy when a simple measured move is enough.
- Passive avoidance: always recommends silence or waiting.
- Premature bluntness: starts with accusation of motive.
- Naive transparency: reveals the full emotional truth before the work-relevant concern.
- False neutrality: lists many options without choosing.
- No usable sentence: gives analysis but no wording when wording would help.

## Correction Checklist

Before finalizing, ask:

1. Is this too generic?
2. Is this assuming bad intent too quickly?
3. Is this ignoring timing, audience, or reputation?
4. Is this missing what not to reveal too early?
5. Is this giving too many options without choosing?
6. Is this missing a usable sentence?
7. Is this drifting into manipulation or status paranoia?
